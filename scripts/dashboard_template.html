Naive vs. honest (walk-forward) backtest

The naive version ranks traders by PnL as scraped today, then scores their whole history — including trades that made them rank highly in the first place. The walk-forward version ranks traders using only PnL realized *before* each point in time, then only scores trades *after* that point, so the ranking can never see what it's about to grade.
